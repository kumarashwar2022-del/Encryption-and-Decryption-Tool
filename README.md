# Encryption-and-Decryption-Tool
A beginner-friendly Python cybersecurity project that demonstrates secure message encryption and decryption using the Cryptography library and Fernet algorithm. The tool generates a secret key, encrypts user-provided messages into ciphertext, and uses the same key to decrypt the ciphertext back into the original message.
